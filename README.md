# Alex's Receipt Parser
This is a personal project that I made since I got annoyed at manually typing out receipts, especially since I went to Costco with 4 friends and had to split like $1000+ and it took me 30 minutes and a spreadsheet to do so. I hope you enjoy! Please do let me know if there are bugs but this is how it works at a very high level:

<img width="989" height="594" alt="Screenshot 2025-11-13 at 5 08 20 pm" src="https://github.com/user-attachments/assets/18e69460-02e7-4ca5-8639-2ba3d8426d24" />

For the frontend code, I used React and Vite, with Netlify to host all the stuff.

For the backend code, I used Modal to run all the inference and models, all the code is written in Python.

Check out the hosted website here: https://alexs-receipt-parser.netlify.app/
